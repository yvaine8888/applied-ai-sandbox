 1. app.py — home() route (lines 19–21)

 Update the route to read q from request.args, filter, and pass q back to the template so the input can stay
 populated:

 @app.route("/")
 def home():
     q = (request.args.get("q") or "").strip()
     if q:
         needle = q.lower()
         notes = [
             n for n in app.notes
             if needle in n["title"].lower() or needle in n["body"].lower()
         ]
     else:
         notes = app.notes
     return render_template("home.html", notes=notes, q=q)

 - Existing note shape is {"title": str, "body": str} (app.py:29) — both fields always strings, no None handling
