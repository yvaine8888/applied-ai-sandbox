# M6 — Other Tools Tour

## Copilot — installed/demo'd
- Observation: When you start typing code, copilot looks at surrounding code for patterns and helps fill in your code based on it (suggests it).

## Cursor (or Windsurf) — installed/demo'd
- Observation: It has an IDE that allows code changes or generation with much of your input.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: They are mostly the same but tell the structure differently.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: It can tell risks, give ideas (learn), and write code but its not to be trusted without review.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md |Claude |Multi file and already has claude.md.
| 5-line helper autocomplete while typing |Copilot |autocomplete
| Brainstorm three design approaches |Chatgpt or claude |Good at giving ideas.
| Review a teammate's PR for security issues |Chatgpt or claude |good at reviewing.
| Cross-file refactor with consistent renames |Cursor |Can see diffs, has IDE, and is better than claude to me.
| Learning a new library's API |Chatgpt or claude |It helps me learn concepts.
